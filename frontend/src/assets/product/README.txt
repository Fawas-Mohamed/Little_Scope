Drop your ice cream images in this folder. They are detected by file name, no code changes needed.

  vanilla.png            main product image (transparent PNG works best): vanilla, strawberry, blueberry, pistachio, mango, chocolate, raspberry
  vanilla-hero.png       optional: hero slider version (hero flavours: vanilla, strawberry, pistachio, chocolate)
  vanilla-peek.png       optional: front-on hover version
  vanilla-photo-1.jpg    optional: Quick View photos 1, 2, 3 (4:5)  (also -close, -ingredients)
  vanilla-garnish-1.png  optional: hero garnish pieces
  instagram-1.jpg ...    Instagram grid (6 tiles)
  story.jpg              Our Story photo
  bag.png                cart bag in the showcase
  room.jpg               showcase background

Missing files fall back to the built-in illustrations.
